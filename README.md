# PS5 homebrew source history

Frozen runtime and ProsperoCraft sources preserved byte for byte from their public canonical repositories. Active development remains in [Java runtime](https://github.com/mateo-cogeanu/ps5-java25-homebrew) and [ProsperoCraft](https://github.com/mateo-cogeanu/ProsperoCraft). This repository does not establish new console acceptance.

## Provenance and integrity

[manifest.json](manifest.json) records every original path, source repository commit, destination, file mode, length and SHA-256, plus the original validation records. Run `python3 verify.py` after cloning. The original repositories retain their complete Git histories, tags and release assets. Package downloads continue to use their original release URLs. No packages, game JARs, caches or raw reports are included.

## Historical builds and licenses

Each snapshot retains its original README, pins, sources and validation. Use its documented entry point and the recorded source commit when additional tooling is outside the snapshot. The `_source-context` folders retain original repository guidance and licensing context. Old external services/toolchains may be unavailable; this migration does not assert every old build is reproducible today. Nested AGENTS.md files are preserved historical documents, not instructions to mutate snapshots. All original copyright, license and attribution notices continue to apply; no blanket relicensing is performed. OpenAL corresponding source/relink assets stay attached to the original releases, and their source pins/builders remain in active ProsperoCraft.
